## Ankündigung kurz
"Funktionen"

Funktionen machen Code wiederverwendbar und übersichtlich. In dieser Session lernt ihr, wie ihr eigene Funktionen definiert, Werte übergebt und zurückgebt und Funktionen wie sorted(), map() und filter() mit eigenen Funktionen kombiniert.

Hallo zusammen,

Wer denselben Code dreimal kopiert, muss ihn auch dreimal korrigieren. Funktionen lösen genau dieses Problem: einmal schreiben, beliebig oft verwenden.

In unserer Live-Session diese Woche schauen wir uns an, wie wir eigene Funktionen schreiben und sinnvoll einsetzen.

Auf dem Programm stehen:

Funktionen mit def definieren und mit Docstrings dokumentieren
Rückgabewerte mit return und der Unterschied zu print()
Parameter, Standardwerte und benannte Argumente
Variable Argumentlisten mit *args und **kwargs
Lambda-Funktionen mit sorted(), map() und filter()


Die Session eignet sich sowohl zum Einstieg als auch zum Auffrischen und Vertiefen. Bringt gerne eure Fragen mit.
